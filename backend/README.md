# EasyGenerator Backend

This workspace contains the NestJS + MongoDB API for the EasyGenerator auth task.

For setup, deployment, and environment variable details, see the root [README.md](../README.md).

Useful commands:

```bash
npm install
npm run start:dev
npm run build
npm test
npm run test:e2e
```
